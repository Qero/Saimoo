# 数据可视化 UI 设计方案

**版本**: v1.0
**日期**: 2026-02-12
**状态**: 已评审

---

## 1. 设计目标

构建一个轻量级、交互式的数据可视化 Web 界面，用于：
- **数据概览**: 查看本地数据库中的股票数据覆盖情况。
- **个股详情**: 展示单只股票的基础信息（代码、名称、上市日期等）。
- **历史走势**: 交互式 K 线图（支持缩放、平移），叠加成交量、均线等技术指标。
- **数据管理**: 提供手动触发数据同步/更新的入口（可选）。

## 2. 技术选型

- **Web 框架**: Streamlit
  - *理由*: 纯 Python 开发，极其适合数据科学与量化可视化，开发效率高，内置丰富的图表组件。
- **图表库**: Plotly / Pyecharts
  - *理由*: 交互性强，支持金融 K 线图 (Candlestick)，易于集成到 Streamlit。本项目首选 **Plotly**。
- **数据源**: 直接读取本地 SQLite 数据库 (`src/saimoo/data/storage`).

## 3. 页面布局设计

### 3.1 侧边栏 (Sidebar)

- **数据源选择**: 本地数据库 / 实时接口 (AkShare)
- **股票选择器**:
  - 输入框: 输入股票代码 (如 `600000`)
  - 列表选择: 从本地数据库已有的股票列表中选择
- **日期范围**: 开始日期 - 结束日期
- **复权类型**: 不复权 / 前复权 / 后复权
- **操作按钮**: "查询", "同步最新数据"

### 3.2 主界面 (Main Area)

#### A. 概览信息 (Header)
- 显示股票名称、代码、最新收盘价、涨跌幅。
- 基础信息卡片: 上市日期、所属行业（如有）。

#### B. K 线走势图 (Chart)
- **主图**: Candlestick (开/高/低/收) + MA (5/10/20/60日均线)。
- **副图**: Volume (成交量) 柱状图。
- **交互**: 鼠标悬停显示详细数据，支持区间缩放。

#### C. 数据表格 (Data Table)
- 展示查询范围内的历史行情数据表格。
- 支持排序、简单的筛选。
- "下载 CSV" 按钮。

## 4. 目录结构规划

```
src/saimoo/web/
├── __init__.py
├── app.py           # Streamlit 入口文件
├── components.py    # UI 组件封装 (K线图、表格等)
└── utils.py         # 数据转换与辅助函数
```

## 5. 实现步骤

1.  **环境准备**: 添加 `streamlit`, `plotly` 依赖。
2.  **后端接口封装**: 在 `saimoo.services.data_service` 中封装面向 UI 的数据查询接口（返回 DataFrame）。
3.  **UI 开发**:
    - 实现侧边栏配置。
    - 实现 K 线图绘制 (Plotly)。
    - 组装主界面。
4.  **启动脚本**: 编写 `run_web.sh` 或集成到 CLI `saimoo ui`。

## 6. 界面语言
- 全界面使用**简体中文**。
