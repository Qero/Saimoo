## 1. 数据源分类与详情

### 1.1 免费/开源类

#### **AkShare** (推荐指数: ⭐⭐⭐⭐⭐)
- **类型**: 开源爬虫聚合库
- **接入方式**: Python SDK (`uv add akshare`)
- **技术规格**:
  - **接口形式**: 直连各财经网站 API (新浪、东财、雪球等)
  - **更新频率**: 实时/准实时 (依赖源站)
  - **数据范围**: 股票、期货、期权、基金、外汇、宏观等全品类
- **优缺点分析**:
  - **性能**: 取决于用户网络及源站响应速度，通常较快。
  - **质量**: 数据源杂，字段命名需统一清洗；偶尔有缺失。
  - **成本**: **完全免费**。
  - **可靠性**: 无 SLA 保障，源站改版会导致接口暂时失效 (修复通常需 1-3 天)。
  - **扩展性**: 极强，社区驱动更新。
- **官方链接**: [AkShare 文档](https://akshare.akfamily.xyz/)

#### **Baostock (证券宝)** (推荐指数: ⭐⭐)
- **类型**: 免费历史数据平台
- **接入方式**: Python SDK (`uv add baostock`)
- **技术规格**:
  - **接口形式**: 需登录的 TCP/IP 协议封装
  - **更新频率**: **非实时** (通常收盘后 1-2 小时更新)
  - **数据范围**: 仅包含 A 股历史 K 线及基础财务数据
- **优缺点分析**:
  - **性能**: 下载历史数据速度尚可。
  - **质量**: 复权处理较准确，但数据维度少。
  - **成本**: **完全免费**。
  - **可靠性**: 维护频率低，服务器偶尔不稳定。
  - **扩展性**: 差，不支持增量实时同步。
- **官方链接**: [Baostock 官网](http://baostock.com/)

### 1.2 付费/商业类 (含部分免费)

#### **Tushare Pro** (推荐指数: ⭐⭐⭐⭐)
- **类型**: 社区化数据平台
- **接入方式**: HTTP REST API / Python SDK (`uv add tushare`)
- **技术规格**:
  - **接口形式**: Token 鉴权，DataFrame 格式返回
  - **更新频率**: 实时 (需高积分) / 延时 (低积分)
  - **数据范围**: 极广，涵盖 A 股全周期数据
- **优缺点分析**:
  - **性能**: API 响应通常在 100ms-500ms 级别，有流控限制。
  - **质量**: 较高，数据结构规范，清洗工作量小。
  - **成本**: 基础数据免费；高频/特色数据需积分 (约 200-5000元/年)。
  - **可靠性**: 较好，有专门团队维护。
  - **扩展性**: 支持增量查询。
- **官方链接**: [官网](https://tushare.pro/) | [积分规则](https://tushare.pro/document/1?doc_id=13)

#### **RQData (米筐)** (推荐指数: ⭐⭐⭐)
- **类型**: 专业商业数据服务
- **接入方式**: Python SDK (`uv add rqdatac`)
- **技术规格**:
  - **接口形式**: 本地 SDK 高速序列化传输
  - **更新频率**: 毫秒级实时 (实盘版) / 收盘后 (回测版)
  - **数据范围**: 专业级深度数据，包含 PIT (Point-in-Time) 数据
- **优缺点分析**:
  - **性能**: 极高，专门优化过的数据传输协议。
  - **质量**: **极高**，经过专业清洗，复权精准。
  - **成本**: 较高 (个人版约 3000+ 元/年)。
  - **可靠性**: 商业级 SLA (99.9%)。
  - **扩展性**: 专为量化设计，易于集成。
- **官方链接**: [定价页面](https://www.ricequant.com/welcome/purchase)

#### **JQData (聚宽)** (推荐指数: ⭐⭐⭐)
- **类型**: 量化平台本地数据服务
- **接入方式**: Python SDK (`uv add jqdatasdk`)
- **技术规格**:
  - **接口形式**: SDK 调用
  - **更新频率**: 实时
- **优缺点分析**:
  - **性能**: 每日有调用条数限制 (如 100万条/日)。
  - **质量**: 优秀，与聚宽在线回测平台一致。
  - **成本**: 中等 (约 3000-6000 元/年)。
  - **可靠性**: 较好。
  - **扩展性**: 适合已有聚宽策略的本地化迁移。
- **官方链接**: [JQData 购买](https://www.joinquant.com/data/dict/jqdata)

#### **Wind (万得)** (推荐指数: ⭐)
- **类型**: 机构级金融终端
- **接入方式**: Windows 终端 COM 接口 (`WindPy`)
- **技术规格**:
  - **接口形式**: 本地终端通信
  - **更新频率**: 实时
- **优缺点分析**:
  - **性能**: 依赖本地终端性能。
  - **质量**: **行业标准**。
  - **成本**: **极高** (数万/年)。
  - **可靠性**: 极高。
  - **扩展性**: 差，仅限 Windows，难以容器化部署。
- **官方链接**: [Wind 官网](https://www.wind.com.cn/)

## 3. Saimoo 项目接入建议

基于 **Saimoo** "面向个人投资者的量化工具" 的定位，以及当前 **Python 3 + UV** 的技术栈，建议采用 **多源融合策略**。

### 3.1 推荐组合方案

1.  **核心数据源 (Primary): AkShare**
    *   **理由**: 零成本覆盖 95% 以上的数据需求，且更新及时。适合作为默认的数据获取渠道。
    *   **用途**: 获取日线行情、实时报价、基础财务数据、龙虎榜等。

2.  **校验与补充源 (Secondary): Tushare Pro (免费/低积分为主)**
    *   **理由**: 数据结构规范，可用于校验 AkShare 数据的准确性。其基础日线数据免费，足以作为校验源。
    *   **用途**: 校验 K 线数据完整性；获取 AkShare 爬取不稳定的特定静态数据（如交易日历、成分股列表）。

3.  **本地存储 (Storage)**
    *   **策略**: 所有获取的数据应立即清洗并持久化到本地数据库 (SQLite/PostgreSQL)，**严禁策略运行时实时请求外网 API** (除实盘交易时段的实时行情外)。

### 3.2 技术集成难度预估

*   **AkShare 集成**: **中等**
    *   *挑战*: 返回的 DataFrame 列名不统一（中文/英文混杂），需要编写一层 Mapping 层将其转换为 Saimoo 的标准字段名。
    *   *应对*: 在 `src/saimoo/data/cleaning` 中建立严格的 Schema 校验。

*   **Tushare 集成**: **低**
    *   *优势*: 原生支持 Pandas，字段定义清晰。

### 3.3 实施路线

1.  **Phase 1**: 引入 `akshare`，实现 `StockDataProvider` 接口，完成历史日线数据的下载与入库。
2.  **Phase 2**: 引入 `tushare`，实现交易日历同步和数据校验功能。
3.  **Phase 3**: (可选) 预留 `RQData` 接口适配器，为未来可能的实盘专业用户提供切换能力。
